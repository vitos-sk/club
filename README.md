# NEXT · закрытый клуб (Telegram Mini App)

Стадия: **приложение на заглушках, без базы данных.** Вся логика клуба работает и проверена тестами; данные лежат в файле `.data/store.json`.

Стек: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Vitest. Бот на grammY — позже, когда будет токен (`bot/README.md`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 232 теста ядра
npm run sim      # симуляция Пульса: числа для отчёта
npm run build    # проверка production-сборки
```

При первом открытии приложение само создаёт тестовых людей. Ты — **№1 Создатель, Основатель** (в Telegram позже: `CREATOR_TG_ID` в `.env`, см. `.env.example`).

## Как проверять руками

Открой приложение и нажми жёлтую полоску «Тест» вверху — это тестовая панель:

- **Кто ты** — переключение между людьми: создатель, Совет, участники, новички на испытательном, кандидаты и гости.
- **Машина времени** — сдвиг на 1/3/7/14/31 день. Сроки клуба — недели и месяцы, так их можно увидеть сразу.
- **Сбросить данные** — вернуть тестовые данные и реальное время.

Что куда ведёт: Холл `/` · Кабинет `/study` · Доска `/board` · Зал встреч `/meet` · Входящие `/inbox` · Люди `/people` · Совет `/council` · Штаб `/staff` · Проверка анкет `/review` · Дежурный `/duty` · Вход кандидата `/join`.

## Устройство

```
core/      вся логика на чистом TypeScript, без Telegram и без базы
  src/       Пульс, кредиты, встречи, доска, отбор, Совет, метрики, плановые задачи, тестовые данные
  test/      232 теста
src/       приложение Next.js (экраны, серверные действия, серверное хранилище-заглушка)
bot/       пока только README
docs/      контекст, инструкция, планы, решения, отчёты
```

Где что менять:
- Цвета и оформление — `src/app/globals.css` (`@theme`), шрифт — `src/lib/fonts.ts`.
- Пороги, сроки, флаги — `core/src/config.ts`. Параметры формулы Пульса — `PULSE_V1` там же.
- Хранилище — `src/server/club.ts`. Когда появится Supabase, подменяется только он (интерфейс `Store`, `core/src/store/store.ts`).
- Решения по архитектуре — `docs/decisions.md`.

## Что остаётся макетом

Экраны «Ключ-карта и QR», «Библиотека», «Карта связей», «Фокус недели», «Пауза», «Каминная» нарисованы, но не подключены: по инструкции это «не делать, пока не попросят» или вторая очередь.
