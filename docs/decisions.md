# Архитектурные решения

Формат: дата · решение · причина. Статус «предложено» = записано в плане, вступает в силу после «ок» заказчика.

## 2026-10-11 · D1 · Работаем на заглушках, без базы данных
**Решение.** Supabase, SQL-миграции, RLS, pg_cron и SQL-views не делаем. Данные хранятся в памяти (по желанию — в локальном JSON-файле для ручных проверок). Весь доступ к данным идёт через один интерфейс `Store`, чтобы потом подставить реализацию на Supabase.
**Причина.** Прямая команда заказчика: «пока делай только с заглушками без базы данных».
**Статус.** Принято.

## 2026-10-11 · D2 · Логика — в пакете `core/` на чистом TypeScript
**Решение.** Пульс, кредиты, правила доски, отбор, Совет и метрики лежат в `core/` как чистые функции: на вход — история и «сейчас» (`now` всегда параметр, не `Date.now()`), на выход — результат. Ни Telegram, ни хранилища внутри нет.
**Причина.** Это тот же расчёт, который потом уедет в SQL (`pulse(member_id, at)` и views). Общие JSON-фикстуры «вход → ожидаемый Пульс» станут эталоном для SQL-версии. Бот и Mini App импортируют одно и то же.
**Статус.** Предложено.

## 2026-10-11 · D3 · Бот — небольшой Node-сервис, не Edge Function
**Решение.** grammY на Node. В разработке — long polling, в проде — webhook на любом хосте с Node.
**Причина.** Напоминания и месячные задачи живут в том же процессе (нужны токен бота и таймеры); у Edge Function лимиты по времени и нет своего расписания. Тесты на Vitest без Deno. Service role key (позже) остаётся только на этом сервере.
**Статус.** Предложено.

## 2026-10-11 · D4 · Планировщик — функция `tick(now)` в процессе бота
**Решение.** Раз в минуту вызывается `tick(now)`: идемпотентные задачи (срок встречи, зависшие запросы, первая помощь новичку, конец испытательного месяца, месячный снимок Пульса, срок Совета). Каждая задача помнит, что уже сделала. `now` подставляется в тестах.
**Причина.** Проверяется Vitest без ожидания реального времени. При переходе на Supabase снимки Пульса можно отдать в pg_cron, а рассылку оставить в боте.
**Статус.** Предложено.

## 2026-10-11 · D5 · Календарные месяцы и кварталы считаем по Europe/Berlin
**Решение.** «Календарный месяц», «квартал», «полный месяц» считаются в часовом поясе `Europe/Berlin`; хранится время в UTC.
**Причина.** Клуб во Фрайбурге; границы месяца по UTC сдвигали бы «срочно раз в месяц», потолок встреч и отчёт.
**Статус.** Предложено.

## 2026-10-11 · D6 · Команды бота — латиницей, русские алиасы через текст
**Решение.** Основные команды латиницей (`/report`, `/guest`…), русские варианты (`/отчёт`, `/гость`) ловятся как текст. Все кнопки и сообщения — по-русски.
**Причина.** Telegram распознаёт как команды только латиницу, цифры и «_». Кириллическая команда не кликабельна и не попадёт в меню бота.
**Статус.** Предложено.
