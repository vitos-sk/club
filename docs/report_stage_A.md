# Отчёт по этапу A (режим заглушек)

Дата: 2026-10-11

## Что сделано

- **Ядро** (`core/`): Пульс по формуле с пятью защитами, кредиты на встречу, доска запросов, подтверждение помощи, дежурный, отбор (кодовое слово → гость → анкета → два проверяющих → звонок → взнос пользой → испытательный месяц → посвящение), Совет (решения, самоотвод, сроки), 10 метрик, месячный отчёт и CSV, плановые задачи с напоминаниями, выход из клуба с обезличиванием.
- **Приложение** (Next.js, тот же макет): Холл, Кабинет, Доска (список, новая записка, отклики, выбор помощника, подтверждение помощи), Зал встреч, Входящие, Люди клуба, Совет, Штаб, Проверка анкет, Дежурный, Вход кандидата, тестовая панель.
- **Ты — основатель №1 и создатель**: открываешь приложение и сразу видишь всё. Переключаться на других людей и двигать время можно в «Тест».
- **Тесты**: 244 теста, все зелёные. Типы и линтер чистые, production-сборка проходит. Формы дополнительно проверены в живом браузере: подтверждение помощи, вход кандидата по нику, оценка анкет, звонок, ошибки правил, «Встретились».

## Симуляция Пульса (40 честных, кольцо из 5, 8 неактивных, 12 месяцев)

| | Ориентир из контекста | Получилось (среднее по 25 прогонам) |
|---|---|---|
| Медиана честных | 56 | 57,8 |
| Нижняя четверть честных | 42 | 42,7 |
| Кольцо | 24 | 13,9 |

Условие «медиана кольца ниже нижней четверти честных» выполняется в 25 прогонах из 25. Кольцо у меня действует жёстче всего: каждый подтверждает каждого каждый месяц на «6». Если кольцо ещё и ходит на встречи с честными, оно набирает около 29 — всё равно ниже. Числа из `npm run sim`. Расхождение с ориентиром по кольцу: в контексте не описано, как кольцо себя ведёт, поэтому допущения мои (в `core/src/simulation.ts`).

## Что не сделано и почему

- **Бот на grammY** — нужен токен. Вся его логика уже в `core/`, список «команда → функция» в `bot/README.md`.
- **База, миграции, RLS, SQL-views, pg_cron** — отложено по твоей команде. Проверки «RLS» заменены слоем доступа и тестами на него.
- **Голосование кнопками в Совете** — решения принимаются действием члена Совета или создателя с обязательной причиной (вопрос 4 плана).
- **Публикация решений в канал «Новости NEXT»** — тексты готовы и видны в Совете, отправка появится с ботом.
- Экраны «Ключ-карта и QR», «Библиотека», «Карта связей», «Фокус недели», «Пауза» остались макетом — это из списка «не делать». Центральная кнопка меню теперь ведёт на Доску.

## Как проверить руками

1. `npm run dev`, открой `http://localhost:3000`.
2. Холл → кабинет: твой Пульс, кредиты, письма благодарности.
3. «Тест» → кто ты: Дмитрий → Доска → «Выбрать помощника» (у него отклики «помощь» и «заказ»).
4. Создатель → Доска → «Мне помогли»: выбери человека, сферу, оценку, отзыв — ему растёт Пульс, приходит кредит.
5. Создатель → Зал встреч: входящий запрос от Анны, «Встретились», потом то же от её имени.
6. «Тест» → Алиса: кодовое слово «Движение», анкета. Потом создатель и Игорь оценивают её в «Проверка анкет». Дальше Штаб: звонок, взнос пользой (за кандидата), приём, посвящение.
7. «Тест» → «+7 дн.»: Лена З. без помощи выходит из испытательного; «+14 дн.»: просроченные встречи, кредит возвращается.
8. Совет → Штаб → «Отчёт» и выгрузка CSV.
